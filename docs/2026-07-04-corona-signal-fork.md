# Corona Signal: форк темы под cogisoft.dev

Решили заменить старый сайт агенства (репо `~/vvbeliaev/cogisoft`, тема
«Parchment Lab» — пергамент/терракота, концептуально несовместима) новым
one-page лендингом в этом монорепо: `apps/cogisoft`. Спека —
`docs/superpowers/specs/2026-07-04-cogisoft-landing-design.md`, тема —
`apps/cogisoft/DESIGN.md`.

**Развилка и решение.** Рассматривали: клон Corona Bloom / сильный форк /
родственный вариант. Выбран **родственный, но различимый** — «Corona Signal»:

- База, шрифты, glow и HUD-ритуалы наследуются 1:1.
- **Инверсия грамматики цветов**: стальной синий = рыночный шум и структура
  (рабочий цвет), коралл = только evidence (CTA, подтверждённые сигналы,
  пройденные gate). У задника агенства осознанно **нет тёплого очага** —
  тепло появляется только там, где рынок сказал «да».
- Вместо звёзд/созвездий по краям — **сигнальное поле** в hero (точки и
  тики-чёрточки = данные, не звёзды): шум → созвездие дорисовывается →
  паттерн вспыхивает кораллом. Анимация буквально показывает бизнес-модель
  (market-first: сигнал → доказательство).

**Отказы.** WebGL-шейдер (старый HeroShader) — отклонён: SVG/CSS дешевле,
в языке бренда и без рисков производительности. Отдельная секция «процесс»
(HADI-цикл) — отклонена как generic; услуги и процесс слиты в одну воронку
из 5 гипотез (Discovery → Offer → Attention → Community → MVP).

**Отложено.** Вынос общих токенов в `pkgs/ts` — до стабилизации второй темы.

## Из спеки лендинга (схлопнуто 2026-09-06)

Отдельная спека `2026-07-04-cogisoft-landing-design.md` удалена, содержательное
из неё — здесь. Коммиты: `a3e32da` (спека), `cfaae00` (реализация).

**Позиционирование того момента** — «venture validation studio», не dev shop и не
маркетинговое агенство. Посыл market-first: продаются закрытые продуктовые
гипотезы, то есть доказательства спроса, а не часы разработки. Разработка —
инструмент проверки, MVP — последний шаг воронки, а не первый. Hero-копия:
«Signals before software». Дифференциаторы, которые обязаны были прозвучать:
«Most agencies start at stage 04. We get there last — on purpose», kill criteria
на каждой ступени, вход возможен на любой ступени.

**Это позиционирование прожило семь недель** и было заменено 29 августа на «одна
единица ответственности на всём пути денег» — см. `2026-08-29-money-path-rail.md`.
Причина смены записана там же; здесь важно, что market-first-рамка не выдержала
столкновения с реальным входящим потоком.

**Вне скоупа v1** значились: кейсы, about, команда, WebGL, блог, формы с
бэкендом, услуги масштабирования — и **вынос темы в общий пакет `pkgs/ts`**.
Последнее показательно: слот `pkgs/*` был спекулятивным с самого начала и
удалён из воркспейса 2026-09-06, так и не получив ни одного жителя.

Старый репозиторий агенства (тема «Parchment Lab», пергамент и терракота) после
запуска ушёл в архив; из него не переносилось ничего.
