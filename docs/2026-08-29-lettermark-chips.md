# Плитки-леттермарки: единая система знаков двух брендов

Запрос был «убрать мигающий символ и поменять фавиконку cogisoft», вырос в
систему знаков для обоих брендов.

Перебрали и отбросили: «c.» с нарисованной точкой (точка-квадрат в фавиконке
читалась странно), signal-cluster (в 16px шум исчезает), wordmark точками
«плотненьким сигналом» (читается, красиво, но в размере шапки сливается в
пунктир — отложен, не принят), шевроны `cs>`, скобки `[cs]`, блок-курсор.

Принято — **сплошные плитки**: `cs` тёмным по кораллу и `vb` тёмным по стали,
JetBrains Mono 800, буквы в кривых (fonttools из самоподдерживаемого woff2),
радиус 14/64, кегль XL (~38/64). Два бренда разнесены цветом при одном строе.
Сплошной выбран против контурного: работа фавиконки — 16px в полосе вкладок,
сплошной цвет читается мгновенно, контур сливается с тёмными темами браузера.

Шапки: cogisoft — голая типографика `cogisoft` (мигающий курсор убран,
utility `animate-blink` удалена); vvbeliaev — `vv` сталью + `beliaev` светлым,
на мобиле вместо V-констелляции плитка vb. Старая фавиконка cogisoft
(восходящая ломаная) нарушала собственное правило «never a line» из
apps/cogisoft/DESIGN.md §2.

Зафиксированное исключение: плитка — единственное место, где брендовый цвет
может быть фоном; на поверхностях страниц цветовая грамматика прежняя.
