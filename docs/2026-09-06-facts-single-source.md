# Факты об авторе: один корень, две ветки производных

Вторая запись того же дня. Первая — про ярусы и модель хранения знания
(`2026-09-06-repo-tiers-and-knowledge-model.md`); эта — про то, как модель
применили к самому дорогому классу фактов: утверждениям о собственной работе.

## Что нашли

Ревизия «где ещё лежит SOT и куда из него копируют» дала предметный улов:

- **Профильный README врал.** `config.ts` держал LLM-Агент в архиве, а README на
  главной странице GitHub звал его «building now». Quizbee: архив против
  «parked». Cogisoft и TraffHub в README отсутствовали вовсе. Самая видимая
  поверхность аккаунта устарела на два обновления.
- **Хендл Telegram лежал захардкоженной копией** в `Contact.astro` рядом с
  собственным конфигом — та же болезнь, что с палитрой, только в разметке.
- **Палитра копировалась в README** отдельными хексами в URL бейджей — четвёртая
  копия темы после `:root`, генератора соцкита и баннера.
- **`backbone.yaml` объявлен источником правды, но генератора нет.** Двадцать
  производных файлов резюме — ручные копии, расхождение не ловится ничем.

## Паттерн

У каждого SOT есть **радиус**. Внутри радиуса — там, где значение читают
напрямую — расхождение невозможно физически. Оно входит ровно в точке, где
значение **копируют наружу**: в другой язык, на другую поверхность, в текст,
написанный руками. Полезный вопрос не «где у меня источник правды», а «где из
него копируют и кто эту копию сверяет».

И производные бывают двух видов, защищаются по-разному:

| Вид | Пример | Порождается | Проверяется |
| :-- | :-- | :-- | :-- |
| Механический | список проектов, каналы, цвета бейджей | скриптом | сверкой, вплоть до CI |
| По суждению | CV под вакансию, что показать на сайте | агентом: выбор, а не трансформация | только покрытием — за словом есть запись |

## Что сделали

**`backbone.yaml` поднят из `private/cv/` в `private/`** — он больше не про
резюме, из него кормится и список проектов. Биография правится только там.

**Публичные факты порождаются.** `labs/profile-readme/generate.mjs` пишет
блоки README между маркерами `facts:` из `config.ts` и палитру из `:root`. Без
зависимостей — Node срезает типы при импорте `.ts`. `--check` стоит в
`guard.yml`: обе стороны публичные, значит сверка работает в CI.

**Публичные утверждения проверяются на опору.** У каждого проекта в `config.ts`
появился `backboneId`; `labs/backbone-check/check.py` (uv, pyyaml) валится, если
он указывает в пустоту или ссылки расходятся. Backbone приватный, поэтому
проверка локальная по построению и молча пропускает себя без файла — в CI её
нет намеренно.

**Сборка CV стала скилом `cv`, а не скриптом.** Отбор пунктов под вакансию —
решение, и скриптом оно не выражается. Скил жёстко запрещает факты вне
backbone и вынос приватного в публичные пути.

## Побочно вскрылось

Глоб `labs/*` в uv-воркспейсе сломался о первый же JS-лаб: uv требует
`pyproject.toml` от каждого участника. Членство стало **явным списком** —
ярус полиглотный по замыслу, и глоб этому противоречил. Ошибка прожила
несколько часов и была найдена использованием, а не рассуждением.

Хендлы Telegram обновлены: `@vvbeliaev_work` для связи, `@vvbeliaev_chan` для
канала. Попутная методическая заметка: t.me отдаёт превью для пользовательских
аккаунтов, но не для каналов — по пустой странице канала нельзя судить, что
его не существует. Проверка контрольным замером по заведомо живому хендлу
опровергла первичный вывод.
