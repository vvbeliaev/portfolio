# labs

Experiments and prototypes. Small things that are built to find something out,
kept in the open unless there is a reason not to be. Some grow into `apps/` and
get a domain, some move to their own repository, most stay here as they are.

A lab is a folder with a README and no obligations — no CI, no deploy. What each
one is and whether it is still alive is in the table below.

| Lab | What it is | Status |
| :-- | :-- | :-- |
| [social-kit](./social-kit) | Generates the Corona Bloom social image masters | `alive` |
| [profile-readme](./profile-readme) | Renders the profile README's facts from the site config | `alive` |
| [backbone-check](./backbone-check) | Checks public claims against the private backbone | `alive` |
