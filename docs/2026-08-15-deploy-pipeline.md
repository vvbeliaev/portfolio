# Деплой vvbeliaev.dev: CI → GHCR → Coolify за Cloudflare Tunnel

Схлопнуто 2026-09-06 из спеки `2026-08-15-vvbeliaev-deploy-design.md`.
Коммиты: `bce20ca` (спека), `2679ea6` (перенос control plane).
Действующий рунбук — скил `vvbeliaev-ops`; здесь только развилки.

**Два решения, задавшие всю схему.**

Первое: **сборка только в CI, сервер никогда ничего не билдит.** GitHub Actions
гоняет `check`, собирает образ, кладёт в GHCR, дёргает Coolify — тот лишь тянет
готовый образ. Репозиторий публичный, значит и пакет в GHCR публичный: ни
лимитов, ни логина при pull. Красный `check` означает, что образа нет и деплоя
не будет — это и есть предохранитель.

Второе: **сервер не светит публичные порты.** Трафик приходит только через
Cloudflare Tunnel (`vvbeliaev-01`, cloudflared как сервис Coolify), TLS
терминируется на краю Cloudflare, Traefik слушает локально. Сервер —
`small-ubuntu-4gb-fsn1-2` (Hetzner fsn1, 2 vCPU / 4 ГБ), на нём живёт ещё
calisthenics, поэтому 80/443 не трогаем вовсе.

**Вне скоупа v1** осознанно оставили: превью на PR, `www`, закрытие 80/443,
чистку старых `sha-*` тегов в GHCR и свой registry. Последнее — переезд одной
строкой `IMAGE`, понадобится при приватном коде или тяжёлых образах.

**Изменение по ходу:** control plane переехал с `coolify.cogisoft.dev` на
`coolify.vvbeliaev.dev` 16 августа. Спека писалась до переезда и до конца
жизни несла старый адрес — типичная болезнь документа, описывающего будущее.
