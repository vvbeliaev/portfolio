# workspace

«Мастерская» — **не-код.** Тексты, брендовые ассеты, стратегия, резюме: всё, что
делается руками и головой, но не запускается. Исполняемое живёт в `labs/`
(эксперименты) и `apps/` (то, что деплоится).

**Репозиторий публичный**, поэтому мастерская разделена на две зоны с жёсткой
границей:

```
workspace/
  assets/          брендовые ассеты — ПУБЛИЧНО, и они действительно уезжают
    corona-bloom-banner.svg      баннер профиля: корневой README тянет его прямой ссылкой
    social/        OG / квадрат / вертикаль / YouTube-баннер (мастера + PNG)
                   генератор к ним — labs/social-kit/
  private/         НИКОГДА НЕ В GIT (.gitignore: workspace/private/)
    cv/            резюме: backbone → reflections → pdf/html
    drafts/        сырые черновики статей: ideas.md + <slug>/main.md
    strategy/      стратегия бренда и дистрибуции, форматы, карта платформ
    refs/          сырые визуальные референсы (скриншоты), не разобрано
    cad/           3D-модели для печати
    projects/      мета-работа по проектам: <name>/ — брифы, заметки, ресёрч
    inbox/         «разобрать»
```

`projects/` и `inbox/` пока пустые — это слоты, а не структура. `private/` живёт
только на машине владельца, бэкап вне git; в клоне его нет.

Статья идёт из кухни в витрину: черновик в `private/drafts/`, выпуск — перенос в
`apps/vvbeliaev/src/content/blog/` и оформление по схеме. Выпуск — это осознанное
повышение, а не смена флага. Конвенции и этапы — в
[`.claude/rules/blog.md`](../.claude/rules/blog.md).

Правила работы с этой папкой (что публично, что приватно, куда что класть) — в
[`CLAUDE.md`](./CLAUDE.md) рядом.
